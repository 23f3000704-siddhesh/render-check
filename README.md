# Overview
This is a simple web app that displays a project status message. For Round 2, a Bootstrap card has been added beneath the introductory text to clearly indicate: "Round 2 update successful!".

# Setup
- No build steps required.
- Open index.html in any modern web browser.

# Usage
- Open index.html.
- Read the introductory text at the top.
- The Bootstrap card directly below shows the current status: "Round 2 update successful!".

# Improvements from Previous Version (Round 2)
- Introduced Bootstrap 5 for consistent styling and responsive layout.
- Added a Bootstrap card component beneath the main text to highlight the Round 2 status.
- Improved visual hierarchy with a header, lead text, and a styled status area.
