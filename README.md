# Overview
This is a minimal static web app that appends a small footer at the bottom of the page. The footer contains the text:
"Verification test completed successfully - Round 3".

# Setup
No build steps are required.
- Download or clone the project.
- Ensure you have a modern web browser.

# Usage
- Open index.html in your browser.
- The footer will appear at the bottom of the page with the specified verification text.
